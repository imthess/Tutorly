# Online Tutoring Marketplace (Tutorly)

**Tutorly** is a Java-based online tutoring marketplace designed to connect students with qualified tutors in a simple, secure, and user-friendly environment. The application enables students to search for tutors, schedule tutoring sessions, join live online classes, and review their learning experience. Tutors can create professional profiles, manage their schedules, accept booking requests, and conduct live tutoring sessions through integrated video conferencing.
