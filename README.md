# Online Tutoring Marketplace (Tutorly)

**Tutorly** is a Java-based online tutoring marketplace designed to connect students with tutors in a simple and secure environment. The application enables students to search for tutors, schedule tutoring sessions, join live online classes, and review their lessons. Tutors can create profiles, manage schedules, accept booking requests, and conduct live classes through integrated video conferencing.
